This is a general readme for installation and running of game.

Follow the instructions for installing Raylib here: https://github.com/raysan5/raylib/wiki/Working-on-Windows 
    NOTE: The Wiki contains other guides for other operating systems, use whichever one you need
Once you've completed that, clone this repo into a folder, open main.cpp, press F5 (in VScode). This should build the game.
    After the build is complete, the game should run. There should also be a .exe file in the folder named "main.exe". This is the executable for the game, and must stay in the folder.
