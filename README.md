This is a general readme for installation and running of game.

The other README file, README-template, is the README file for the project template created by Programming with Nick, and his tutorial on this topic is incredibly useful as well. 
    The "bouncing ball" demo has been replaced with the Pong game, but the structure and layout of the template remains unchanged.

Install the Raylib Installer here:
    https://www.raylib.com/ 
Follow the instructions for installing Raylib at these links: 
    https://github.com/raysan5/raylib/wiki/Working-on-Windows
    https://github.com/raylib-extras/raylib-quickstart

NOTE: The Wiki contains other guides for other operating systems, use whichever one you need. For Windows, make sure to set add the filepath to your w64devkit bin folder, should be in something similar to what is shown below.
        C:\raylib\w64devkit\bin
    
Once you've completed that, use git to clone this repo into a folder, and open the folder in VS Code
    Once the folder is opened, select main.cpp, and press F5. This should build and run the game.
     There should also be a .exe file in the folder named "main.exe". This is the executable for the game itself, and can be used to run the game without opening VS Code.
